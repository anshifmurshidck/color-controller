# Color Controller

A simple React app that changes a box color using buttons.

## Features
- Click **Green** to set the box color to green
- Click **Red** to set the box color to red
- Click **Reset** to clear the color

## Concepts Used
- useState
- Event Handling
- Conditional Rendering
- Dynamic Styling

## How to Run
```bash
npx create-react-app color-controller
cd color-controller
npm start
```
